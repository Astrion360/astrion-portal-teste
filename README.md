# Astrion — apresentação comercial

Apresentação de 69 telas, baseada diretamente no arquivo ASTRION_Portal_Keynote_Apresentacao.html fornecido pelo usuário. O conteúdo, os dados, as notas e a ordem das telas foram preservados.

Abra https://astrion360.github.io/astrion-portal-teste/ ou baixe index.html e abra no navegador. O arquivo é autônomo: imagens, estilos e scripts estão incorporados.

Navegação: setas, menu por capítulo, índice pesquisável e modo explorar. Há notas para o apresentador e opção de tela cheia. No celular, cada tela permite rolagem vertical; as tabelas largas possuem rolagem própria.

A revisão de interface não constitui atualização das informações comerciais e das datas-base presentes no documento original.
